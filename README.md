# Recappy Review — 英文からAnki用の復習CSVを作るツール

学習した英文と分からなかった単語を入力し、**文脈付きの例文・単語の意味・日本語訳**
をAnki用の2列CSVにまとめるWebツールです。

単語ごとに例文を探してカードへ転記する作業を、一つの画面で進められるようにしています。
リポジトリ名は `nativecamp-review-tool`、画面上の名称は **Recappy Review** です。

## できること

1. 英文と復習したい単語を入力する
2. 本文から単語を含む文を抽出する
3. 辞書・翻訳サービスから意味、品詞、例文の訳を取得する
4. プレビューで表裏の内容を編集し、不要な行を削除する
5. CSVをダウンロードし、Ankiへ取り込む

## 起動方法

GitとPython 3が利用できる環境で、次を実行します。

```bash
git clone https://github.com/GitTarochan/nativecamp-review-tool.git
cd nativecamp-review-tool
python3 -m http.server 8000
```

[http://localhost:8000](http://localhost:8000) を開いてください。
アプリ自体はHTML・CSS・JavaScriptで構成され、ビルドやPythonパッケージの導入は不要です。
辞書・翻訳の取得にはインターネット接続が必要です。

## 入出力例

- 英文：`I enjoy reading books. This novel is fascinating.`
- 復習する単語：`fascinating`
- CSVの1列目：`This novel is fascinating.`（対象語をHTMLで強調）
- CSVの2列目：取得した単語の意味・品詞、日本語訳

訳文は外部サービスの応答によって変わります。
これは処理の説明例であり、翻訳結果を固定したテスト結果ではありません。

## Ankiへの取り込み

- ヘッダー行のない2列CSVです。
- 1列目をカードの表、2列目を裏に割り当てます。
- 単語の強調表示にはHTMLを使うため、取り込み時にHTMLとして扱う設定を確認してください。
- CSVはUTF-8 BOM付きで出力します。
- インポート前にプレビューで意味と例文を確認してください。

## 技術・実装のポイント

| 項目 | 実装 |
|---|---|
| 画面・処理 | HTML、CSS、JavaScriptを [index.html](index.html) に収録 |
| 例文抽出 | 文への分割と正規表現による単語照合 |
| 辞書 | Dictionary API |
| 翻訳 | Googleの翻訳エンドポイント、MyMemory APIへのフォールバック |
| 出力 | 編集可能なプレビュー、CSVエスケープ、ブラウザでのファイル生成 |

外部サービスが応答しない場合の表示や、ユーザーが結果を修正できる導線を実装しています。
作業時間の削減率・利用者数などの定量的な効果は測定していません。

## データの扱い・制約

- 辞書へ照会する単語、翻訳対象の単語・抜粋文は外部サービスへ送信します。
- 外部サービスの仕様変更、利用制限、通信状況によって取得に失敗する場合があります。
- 意味や品詞は文脈に最適とは限りません。多義語や活用形は手動確認が必要です。
- 本文に一致する文がない場合は、その旨を表示します。
- 意味や訳は表示用に長さを制限しています。必要に応じてプレビューで補ってください。
- アカウント同期や、ページを閉じた後の編集内容の復元機能はありません。
